## 🚀 Selected Experience

### 📊 Enterprise Expense Analysis Agent

Designed and developed an enterprise AI assistant for accounting and expense analysis, combining:

`Intent Understanding` → `Parameter Extraction` → `Data Retrieval` → `Drill-down` → `LLM Summarization`

The system was designed around reliable structured workflows rather than relying entirely on free-form LLM reasoning.

---

### 💰 Financial LLM Pipeline

Built a multi-stage AI pipeline on **Azure Databricks** for processing financial data and generating structured insights across:

- Inventory
- Accounts Receivable
- Accounts Payable
- Financial reporting workflows

The pipeline combined data processing, parallel execution, and LLM-generated business insights for downstream dashboards.

---

### 📑 Multimodal Document Intelligence

Developed document-processing pipelines using **OCR and multimodal LLMs** to extract:

- Structured information
- Charts
- Annotations
- Comments
- Executive insights

from complex business documents and PDF reports.

---

### 🇹🇭 Thai NLP Services

Fine-tuned transformer-based NLP models for Thai language applications including:

- Text summarization
- Spelling correction
- Support email processing

and exposed them through production REST APIs.
